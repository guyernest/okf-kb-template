This is the starter document that came with the template. Replace it with your first real document, and add a line for
every new document to the `index.md` of its folder (the check warns about a document its index does not list).

To report a wrong answer, missing knowledge or a document that needs to change, open an issue with one of the three issue
forms of this repository. A maintainer can then ask the agent to propose the change as a pull request; the agent and the
rules skill follow `.claude/skills/okf-kb-rules/`.
